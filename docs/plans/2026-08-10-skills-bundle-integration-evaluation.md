### Recommended new integrations (2 repos)

#### 4. EveryInc/compound-engineering-plugin (MIT, 24.2k★, very active)

- **32 skills** at `skills/<name>/SKILL.md`, deliberately harness-neutral.
- Copilot is a documented first-class target. Zero `$ARGUMENTS`/`mcp__` coupling in skill bodies.
- **Cherry-pick strategy**: Add the non-review skills only.
  - **ADD**: ce-ideate, ce-brainstorm, ce-plan, ce-work, ce-compound, ce-debug, ce-simplify-code, ce-commit, ce-commit-push-pr, ce-babysit-pr, lfg, ce-strategy, ce-product-pulse, ce-sweep, ce-compound-refresh, ce-pov, ce-explain, ce-optimize, ce-retune, ce-worktree, ce-handoff, ce-promote, ce-dogfood, ce-test-browser, ce-test-xcode, ce-setup, ce-doc-review
  - **SKIP** (duplicate existing bundle review skills): ce-code-review, ce-resolve-pr-feedback
- **Conflict**: ce-code-review ≈ code-review-and-quality ≈ gstack-review ≈ requesting-code-review. ce-resolve-pr-feedback ≈ receiving-code-review ≈ sp-receive-review.
- Bundled scripts need Node/Python; optional external CLIs (gh, codex, claude, grok) degrade gracefully.

#### 5. Shubhamsaboo/awesome-llm-apps (Apache-2.0, trending, verified July 2026)

- **7 skills** in `agent_skills/`, all `SKILL.md`-spec compliant, agent-agnostic.
- Zero Claude-Code coupling. Copilot explicitly supported as install target.
- **ADD 4 deterministic skills**: commit-archaeologist, scope-creep-detector, dependency-doctor, project-graveyard.
  - Each ships stdlib-only Python scripts, CI-eval-gated.
- **SKIP**: self-improving-agent-skills (standalone FastAPI+Next.js web app, not a drop-in skill).
- **SKIP**: advisor-orchestrator-worker, thinking-out-loud (lighter value, can add later if needed).
- No conflicts with any existing bundle skill.

### Optional / deferred (2 repos)

#### 6. msitarzewski/agency-agents (MIT, 141k★, very active)

- 230+ domain-expert agent persona files (Markdown + YAML frontmatter).
- No SKILL.md in source; `SKILL.md` generated only for Antigravity/Osaurus targets.
- No conflicts — orthogonal (domain personas vs process skills).
- **Decision**: Defer. Large surface (230+ files); would need curation by division (engineering/security/testing). Can add a curated subset in a future pass.

#### 7. microsoft/agent-governance-toolkit (MIT, 5.8k★, active)

- 1 portable skill: `agt-policy-authoring` (host-neutral, no Claude coupling).
- No conflicts — complementary to security-and-hardening, security-review, azure-compliance.
- **Decision**: Defer. Low standalone value — the skill authors a `.agt/policy.json` that no runtime auto-enforces without the Copilot CLI extension. Can add the skill alone if governance enforcement becomes a priority.

### Skipped (3 repos)

#### 8. huangruiteng/loopx (MIT, 3.8k★, very active)

- **High Claude-Code coupling**: `$ARGUMENTS`, `/loop`, `Bash(...)`, slash commands, `PreToolUse` hooks, MCP tools.
- Skills are thin wrappers over `loopx` CLI calls — would need CLI + MCP server installed.
- **Strongest overlap** with `ar-autoresearch` (auto-research capability with same shape).
- **Moderate overlap** with `loop-engineering` / `continuous-agent-loop` (governance concepts).
- **Decision**: Skip. Would require significant re-wiring for Copilot; duplicates existing bundle concepts.

#### 9. zhaoxuya520/reverse-skill (Mixed licensing, 22.8k★, active)

- ~40 security/RE/pentest skills + 42 CTF sub-skills.
- **Mixed licensing**: MIT core + **GPLv3 CTF sub-tree** + **AGPL-3.0 Pentest Swarm** — incompatible with bundling.
- Heavy install footprint: many MCP servers, external RE tools (jadx, Frida, IDA, Ghidra, BurpSuite).
- Claude-Code-specific `Skill(...)` / `$var` syntax in CTF sub-tree and docs-generator.
- Offensive-tooling policy concerns.
- **Decision**: Skip. Licensing + tooling footprint + policy concerns outweigh value.

#### 10. JZKK720/TencentDB-Agent-Memory (MIT, upstream 19k★)

- Server-side memory backend (Node 22+ Redis + Docker + LLM upstream). Not a skills source.
- Skills are OpenClaw-bound operational skills — would break under VS Code Copilot.
- Conceptually overlaps gbrain/memory/knowledge-ops/context-engineering/headroom (different layer).
- **Decision**: Skip. Would require full infrastructure deployment, not a skills-bundle addition.
